# Ajustes a la página Ventas y POS

## 1. HeroSubtitle — unificar para reforzar el hero

### Actual
```
heroSubtitle: 'Presupuesto, POS y factura electronica en un mismo flujo. Vende en mostrador u online con stock y precios sincronizados entre sucursales.',
```

### Problema
Dos oraciones que compiten: una habla del flujo interno (presupuesto→POS→factura), la otra habla de canales y sucursales. Ninguna termina de resonar porque la atención se divide.

### Corrección
```
heroSubtitle: 'Presupuesto, POS y factura electronica en un mismo flujo. Con stock y precios sincronizados en todas tus sucursales.',
```

**Por qué:** La segunda oración ahora refuerza el hero en vez de abrir un tema nuevo (canales). "En todas tus sucursales" es más contundente que "entre sucursales".

## 2. Observación sobre tono (vos vs tú) — decisión del equipo

### Actual (tú)
```
'Agenda una demo'
'Gestiona presupuestos...'
'Vende mas y mas rapido'
```

### Alternativa (voseo — versión acordada en sesión anterior)
```
'Agendá una demo'
'Gestioná presupuestos...'
'Vendé más y más rápido'
```

### Decisión
El copywriter de la sesión anterior estableció voseo para el sitio completo. Si se decide mantener "tú", hay que asegurar consistencia en todas las páginas. Mezclar ambos registros se nota.

**Acción:** El equipo define si todo el sitio va en "tú" o en "vos", y se unifica.

## 3. Description sección 1 (densidad)

### Actual
```
'El flujo comercial puede recorrer Cotizacion, Presupuesto, Pedido y Venta, pero no obliga a empezar siempre en el mismo punto: puedes iniciar en cualquiera de las etapas segun como llegue la oportunidad. En el camino, tambien puedes aplicar upselling sin romper la trazabilidad.'
```

### Observación
Tiene 3 ideas: (a) el flujo tiene etapas, (b) podés empezar en cualquiera, (c) upselling con trazabilidad. Funciona pero es denso para escaneo rápido.

### Opción de ajuste (sugerida)
```
'Arrancas por donde te llegue la oportunidad: cotizacion, presupuesto, pedido o venta directa. Despues podes sumar productos con upselling sin perder la trazabilidad.'
```

**No bloqueante.** La versión actual es correcta. Esta es una mejora menor si hay tiempo.
